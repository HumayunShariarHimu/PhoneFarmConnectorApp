PHONEFARM / ANDROID CONNECTOR

PhoneFarm Android

An owner-visible Android connector for authorized device quality assurance. Pair a real Android phone with PhoneFarmZone, select APKs through Android’s standard installer, and launch approved test targets.

Download latest APK View source repository

Install the APK

  1. Tap Download latest APK and download the APK asset from GitHub Releases.
  2. Open the downloaded file on your Android phone. If Android asks, enable Allow from this source for the browser or file manager that opened the APK.
  3. Review the Android installer screen and approve the installation. The app never performs a silent install.
  4. Open PhoneFarm. In PhoneFarmZone, sign in as the owner and choose Pair Android.
  5. Enter the one-time six-digit code in PhoneFarm. Pairing requires explicit owner consent and can be revoked at any time.

What this build supports

  • Secure owner pairing and heartbeat status.
  • User-approved APK handoff to Android Package Installer.
  • Launching an already-installed app by package name.
  • Authorized QA coordination with the PhoneFarmZone dashboard.

Important platform boundary

This is an authorized QA connector, not a hidden-access tool or a full Android OS clone. A normal Android app cannot create ten independent Android phones inside one host phone. For a real multi-device lab, use multiple physical Android devices or emulator hosts.
